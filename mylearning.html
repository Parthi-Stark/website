22

WAF does NOT replace a firewall

This is a very important concept.

A network firewall primarily controls network traffic.

For example

IPPortProtocolNetworkZone

A WAF primarily protects web applications.

For example

HTTPURLParametersHeadersCookiesRequest bodyApplication attacks

So

Firewall

"Can this network connection reach the service?"

WAF

"Is this HTTP request acceptable for this application?"

Example

24

TLS termination

In many enterprise architectures

Client│HTTPS↓WAF / Load Balancer│HTTP or HTTPS↓Backend

TLS terminates at the WAF/LB.

Alternatively

Client↓ HTTPSWAF↓ HTTPSLoad Balancer↓ HTTPSWeb Server

This is called TLS re-encryption / SSL bridging depending on architecture.

25

Why does the WAF need TLS termination?

Because encrypted traffic looks like

Random encrypted bytes

The WAF cannot inspect

SQL injectionXSSURLPOST body

unless it can decrypt the traffic.

So

HTTPS↓TLS termination↓HTTP inspection↓WAF rules

This is a major WAF concept.

403 vs 404 vs 500 vs 502 vs 503

Know these extremely well.

200Success301/302Redirect400Bad request401Authentication required/failed403Forbidden

Could be WAF or application.

404Resource not found429Too many requests500Application/server error502Bad gateway

Often proxy/LB cannot get a valid backend response.

503 Service unavailable

Backend/pool/service may be unavailable.

504 Gateway timeout

Proxy/LB waited too long for upstream.

OSI model you should know

For your career, memorize this conceptually.

Layer 7 → Application
          HTTP, HTTPS, DNS
Layer 6 → Presentation
          TLS, encoding
Layer 5 → Session
Layer 4 → Transport
          TCP, UDP
Layer 3 → Network
          IP, routing
Layer 2 → Data Link
          Ethernet, MAC, VLAN
Layer 1 → Physical
          Cable, fiber, radio
